## Personal

Side projects I work on outside of my day job, usually born out of curiosity

<div class="grid cards" markdown>

-   :lucide-music-4:{ .lg .middle } __Spotify SDK__

    ---

    `spotify-sdk` is a Python client for the
    [Spotify Web API](https://developer.spotify.com/documentation/web-api).
    It provides sync and async interfaces with type-safe responses, so you
    can build apps against Spotify without managing raw HTTP or JSON.

    :octicons-book-16:{ .middle } [Documentation](https://spotify-sdk.dev)

    :octicons-mark-github-16: [GitHub](https://github.com/jonathan343/spotify-sdk)

-   :lucide-cat:{ .lg .middle } __Catppuccin Zensical__

    ---

    A soothing pastel theme for [Zensical](https://zensical.org/) documentation sites, built on the
    [Catppuccin](https://catppuccin.com/) palette. It registers an installable `catppuccin` theme that
    extends Zensical's Material-compatible default, adding all four official
    flavors.

    :octicons-book-16:{ .middle } [Documentation](https://jonathan343.github.io/catppuccin-zensical/)

    :octicons-mark-github-16: [GitHub](https://github.com/jonathan343/catppuccin-zensical)

## Work

These are some projects I maintain for work at Amazon Web Services (AWS).

<div class="grid cards" markdown>

-   :fontawesome-brands-aws:{ .lg .middle } __boto3__

    ---

    The official AWS SDK for Python. Comprised of `boto3`, the high-level
    user-facing client; `botocore`, the low-level core that also powers the
    AWS CLI; and `s3transfer`, a library for managing efficient Amazon S3
    transfers.

    :octicons-mark-github-16: [boto3](https://github.com/boto/boto3)

    :octicons-mark-github-16: [botocore](https://github.com/boto/botocore)

    :octicons-mark-github-16: [s3transfer](https://github.com/boto/s3transfer)

-   :fontawesome-brands-aws:{ .lg .middle } __aws-sdk-python__

    ---

    The next generation of the AWS SDK for Python, built on [Smithy](https://smithy.io/).
    Comprised of `aws-sdk-python`, the AWS-specific SDK, and `smithy-python`, the
    underlying code generator and runtime for Smithy-based clients in Python.

    :octicons-mark-github-16: [aws-sdk-python](https://github.com/awslabs/aws-sdk-python)

    :octicons-mark-github-16: [smithy-python](https://github.com/smithy-lang/smithy-python)

</div>
